# 임신 주수 계산기

마지막 생리 시작일과 계산 기준일을 입력하면 현재 임신 주수, 임신 경과일과 예상 출산일을 계산해 주는 간단한 HTML 웹 프로젝트입니다.

## 프로젝트 주제

마지막 생리 시작일을 기준으로 임신 기간을 계산하고, 평균 임신기간 280일을 적용하여 예상 출산일을 보여줍니다.

## 입력·처리·출력

| 구분 | 내용 |
| --- | --- |
| 입력 | 마지막 생리 시작일, 계산 기준일 |
| 처리 | 두 날짜의 차이를 계산하고 마지막 생리 시작일에 280일을 더함 |
| 출력 | 임신 경과일, 현재 임신 주수, 임신 단계, 예상 출산일 |

## 계산 방법

- 임신 경과일 = 계산 기준일 - 마지막 생리 시작일
- 임신 주 = 임신 경과일을 7로 나눈 몫
- 남은 일수 = 임신 경과일을 7로 나눈 나머지
- 예상 출산일 = 마지막 생리 시작일 + 280일

예를 들어 마지막 생리 시작일이 2026년 7월 7일이고 계산 기준일이 2026년 8월 13일이면 임신 경과일은 37일이며, 현재 임신 주수는 5주 2일로 계산됩니다.

## 주요 기능

- 마지막 생리 시작일 입력
- 계산 기준일 입력 및 오늘 날짜 자동 설정
- 현재 임신 주수와 경과일 계산
- 임신 초기·중기·후기 안내
- 예상 출산일과 예정일까지 남은 기간 표시
- 잘못된 날짜 입력 확인
- PC와 스마트폰 반응형 화면
- 별도 설치 없이 브라우저에서 실행

## 실행 방법

1. 저장소에서 `index.html` 파일을 다운로드합니다.
2. 다운로드한 파일을 더블클릭합니다.
3. Chrome 또는 Edge에서 날짜를 입력합니다.
4. **임신 주수 계산하기** 버튼을 누릅니다.

## 주의사항

계산 결과는 평균 28일 생리주기와 마지막 생리 시작일을 기준으로 한 예상값입니다. 생리주기, 배란일과 착상 시점에 따라 실제 임신 주수와 출산예정일이 달라질 수 있습니다. 정확한 결과는 산부인과 진료와 초음파검사를 통해 확인해야 합니다.
